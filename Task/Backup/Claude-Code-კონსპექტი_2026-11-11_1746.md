# Claude Code — ჩემი სასწავლო კონსპექტი

განახლდა: 2026-11-11 · გიორგი ჭეიშვილი

## ყოველდღიური დაწყება

Claude Code-ის გასაშვებად სამი ნაბიჯია საჭირო: ტერმინალი, პროექტის საქაღალდე და ბრძანება claude.

1. გახსენი Windows Terminal (არა ძველი PowerShell-ის ფანჯარა): Start მენიუში მოძებნე „Terminal“.
2. გადადი პროექტის საქაღალდეში:

```powershell
cd D:\claude-learning
```

3. გაუშვი Claude Code:

```powershell
claude
```

4. შეამოწმე ქვედა ზოლი: თუ წერია auto mode on ან accept edits on, Shift+Tab-ით გადართე ჩვეულებრივ რეჟიმზე, სადაც წარწერა არ ჩანს.
5. ახალი ამოცანის წინ აკრიფე /clear.

დასასრულებლად: /exit ან ორჯერ Ctrl+C.

## დღე 1 — 10–11 ნოემბერი: დაყენება და პირველი სამი პროექტი

შედეგი: Claude Code მუშაობს საქაღალდეში D:\claude-learning და იქ სამი გვერდია: index.html, about.html, calculator.html.

### გაკვეთილი 1: დაყენება და პირველი გვერდი

- დაყენება Windows-ზე (PowerShell): irm https://claude.ai/install.ps1 | iex
- შესვლა: პირველ გაშვებაზე ვირჩევთ Claude ანგარიშს (Pro), არა Anthropic Console-ს.
- უსაფრთხოება: Claude Code ვუშვებთ მხოლოდ პროექტის საქაღალდეში, არასდროს C:\Users\... საქაღალდეში ან მთელ დისკზე.
- „Trust this folder“ კითხვაზე Yes მხოლოდ მაშინ, როცა საქაღალდის გზა სწორია.
- CLAUDE.md: მუდმივი ინსტრუქციები, რომლებსაც Claude Code ყოველი სესიის დასაწყისში კითხულობს. ჩემსაში წერია: დავალებას ქართულად ვწერ, პასუხს რუსულად ვიღებ, გვერდები ქართულად რჩება.
- შრიფტი: Windows Terminal → Settings (Ctrl+,) → Profiles → Defaults → Appearance → Font face: Cascadia Mono, Sylfaen.
- პირველი პროექტი: index.html — „გამარჯობა“ და ღილაკი, რომელიც ფერს იცვლის.

### გაკვეთილი 2: ვიზიტკა გვერდი (about.html)

- Plan mode: ჯერ გეგმა, მერე მუშაობა. გამოვიყენოთ დიდი ამოცანების წინ.
- გეგმის დადასტურებისას ვირჩევთ 2. Yes, manually approve edits.
- ცვლილების დადასტურებისას ვირჩევთ 1. Yes: წითლად (−) რა წაიშლება, მწვანედ (+) რა დაემატება.
- ერთ ჯერზე ერთი პატარა ცვლილება → შემოწმება ბრაუზერში (F5) → შემდეგი.
- ფაილი თვითონაც შევცვალე Notepad-ში (Ctrl+S).

### გაკვეთილი 3: კალკულატორი (calculator.html)

- HTML ჩონჩხია, CSS გარეგნობა, JavaScript ქცევა.
- ცვლადი (variable): ყუთი, სადაც მნიშვნელობა ინახება. ფუნქცია (function): ბრძანებების ჯგუფი სახელით. მოვლენა (event): მომხმარებლის მოქმედება, მაგალითად დაჭერა.
- @ფაილი მოთხოვნაში სხვა ფაილს უცავს, მაგალითად „about.html-ის სტილში“.
- Edge case (კიდური შემთხვევა): 10 ÷ 0 აჩვენებს „შეცდომა“-ს, არა Infinity-ს.
- შეცდომის (bug) აღწერა: რა გავაკეთე → რა მოხდა → რას ველოდი.
- დავამატეთ: ისტორია, ღამის რეჟიმი, წაშლის ღილაკი.

## დღე 2 — 11 ნოემბერი: Git, პროექტის „დროის მანქანა“ (მიმდინარე)

Git პროექტის ვერსიებს სამუდამოდ ინახავს, /rewind კი მხოლოდ ერთი სესიის ფარგლებში.

| ტერმინი / ბრძანება | რას ნიშნავს |
| --- | --- |
| repository (repo) | საქაღალდე, რომლის ისტორიასაც Git ინახავს |
| commit | ერთი შენახული ვერსია მოკლე აღწერით („save point“) |
| git init | ქმნის repository-ს |
| git add + git commit | ამზადებს და ინახავს ვერსიას |
| git diff | აჩვენებს, რა შეიცვალა ბოლო commit-ის შემდეგ |
| git log | აჩვენებს commit-ების ისტორიას |
| git restore | ფაილს ბოლო commit-ის მდგომარეობაში აბრუნებს |

სავარჯიშოები:

- [ ] Git-ის შემოწმება და სახელის/ელფოსტის დაყენება
- [ ] პირველი repo და პირველი commit
- [ ] ცვლილება about.html-ში, git diff და მეორე commit
- [ ] calculator.html-ის „გაფუჭება“ და Git-ით აღდგენა
