| noreply ელფოსტა | GitHub-ის ფარული მისამართი: commit-ები ჩემს ანგარიშს ებმის, ნამდვილი ფოსტა კი არ ჩანს |
| .gitignore | ფაილი სიით: რომელ ფაილებს და საქაღალდეებს არ უნდა აკვირდებოდეს Git |

### .gitignore

- .gitignore-ში ჩავწერე Task/Backup/: ბექაფები აღარ ხვდება commit-ში.
- git rm -r --cached Task/Backup: Git-იდან ამოიღო, კომპიუტერიდან არ წაუშლია (--cached ამისთვისაა).
- ყურადღება: ძველ commit-ებში ბექაფები მაინც რჩება და GitHub-ის ისტორიაში ჩანს.

### GitHub-ზე ატვირთვა

| ტერმინი | რას ნიშნავს |
| --- | --- |
| GitHub | საიტი, სადაც Git-ის პროექტები ინტერნეტში ინახება |
| remote / origin | GitHub-ის მისამართი, სადაც პროექტი იტვირთება; origin მისი სახელია |
| push | commit-ების ატვირთვა GitHub-ზე |
| pull | GitHub-იდან ცვლილებების ჩამოტვირთვა |
| ahead 1 | კომპიუტერზე 1 commit-ია, რომელიც GitHub-ზე ჯერ არ არის |

- რიგი: git remote add origin მისამართი → git branch -M main → git push -u origin main.
- პირველ push-ზე იხსნება GitHub-ში შესვლის ფანჯარა. Windows იმახსოვრებს, მეორედ აღარ ითხოვს.
- ყოველდღიური ციკლი: ცვლილება → git status → git add . → git commit -m "..." → git push.
- git add .-მდე სასარგებლოა git diff. თუ GitHub-ის საიტზე რამე შეცვალე, ჯერ git pull.

### GitHub Pages: პროექტი საიტად

GitHub Pages ჩემს HTML გვერდებს უფასოდ აქცევს საიტად, რომელიც ნებისმიერს შეუძლია გახსნას ბმულით.

- ჩართვა (ერთხელ, ბრაუზერში): repository → Settings → Pages → Deploy from a branch → main / (root) → Save.
- საიტის მისამართი: https://gtcheishvili.github.io/claude-learning/ + ფაილის სახელი, მაგალითად https://gtcheishvili.github.io/claude-learning/about.html
- ყოველი git push-ის შემდეგ საიტი თავისით ახლდება 1-2 წუთში. თუ ცვლილება არ ჩანს, დაიცადე და ბრაუზერში F5.
- საიტზე მხოლოდ ის ჩანს, რაც push-ით აიტვირთა. commit push-ის გარეშე საიტზე არ გამოჩნდება.
